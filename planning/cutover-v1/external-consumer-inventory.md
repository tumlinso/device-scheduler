## Armed state and evidence limits

Project Control’s read-only frontier returned no ready work for KDA or FrameShift at 2026-10-21 16:34 UTC. That is not a read of the CUDA controller’s private watch database and does not prove that no watch is armed. The documented controller interface has a project inspection command and explicit background controls, but those commands were not run for this source-only task. Therefore, the current set of armed watches, queued campaign jobs, live controller executions, and physical owners is **unknown**. Resolve it through the supported read-only controller/status route during the DS-13 pre-cutover gate; reconcile or explicitly retire every item before fencing admissions.

Project Control consumers and the unresolved live controller runtime binding are covered separately by [`consumer-map.json`](consumer-map.json). The frontiers and static source identity checks do not prove that only one allocator is active or that any extant allocation was reclaimed.
